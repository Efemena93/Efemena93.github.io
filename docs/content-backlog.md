# Content backlog

Author notes that used to live inside the case studies as `todo` blocks. They
were rendering on the public pages as dashed "To write" panels — on the three
strongest case studies, which is the worst possible place for them.

Nothing here is deleted; it is moved. Each note still says exactly what it said
before, and names the case study and section it belongs to. Work through these
and the pages get better; ignore them and the pages are still complete and
publishable, which was not true before.

Scaffolded projects (Windchill, VocHub, VirtualBuddy) keep their `todo` blocks
in place — they are drafts, so those blocks never reach a public build. Run
`npm run content:todo` for the full list including those.
